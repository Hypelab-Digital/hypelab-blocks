# Praxis — Propuesta de rediseño

Demo interna de Hypelab: rediseño de la página [Medición de experiencia de clientes](https://praxis.cl/medicion-experiencia-de-clientes/) de Praxis.

- Contenido: el original de praxis.cl (sin cambios de fondo).
- Diseño: nueva dirección visual inspirada en referencias aportadas por marketing, con más movimiento (animaciones de scroll, contadores, gráfico animado, marquee de clientes, slider de testimonios).
- Colores de marca Praxis conservados (`#75B9A6` / `#3C3C3B`).
- El menú replica la navegación real pero sin enlaces funcionales.

Sitio 100% estático (HTML + CSS + JS vanilla), sin build. Deploy directo en Vercel.
